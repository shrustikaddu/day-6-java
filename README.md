# Java Inheritance and Method Overriding

## Description
This program demonstrates Inheritance and Method Overriding in Java.

## Concepts Covered
- Inheritance
- Parent Class and Child Class
- extends Keyword
- Method Overriding
- Main Method

## Program Explanation
- Class A is the parent class.
- Class B is the child class that extends class A.
- Both classes contain a display() method.
- Class B overrides the display() method of class A.
- The child class method is executed when the object of B calls display().
